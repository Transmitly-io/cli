# @transmitly/cli

```bash
export TRANSMITLY_API_KEY=txk_...
npx @transmitly/cli emails send --from "Notify <notify@acme.com>" --to ada@example.net --subject "Hi" --html "<p>Hi</p>"
```

Commands: `emails send`, `emails get`, `messages list`, `domains list`, `webhooks list`, `test-mode simulate`. Set `TRANSMITLY_BASE_URL` for local testing.
